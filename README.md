# 6150-group_Assignment


**Finsight** is an  personal finance management web application designed specifically for young bachelors to help them manage their budgets effectively. The platform provides smart budgeting tools, expense tracking and personalized financial recommendations.

### Purpose
To empower young adults with tools and insights needed to take control of their financial future through intelligent budget management and data-driven decision making.

### Authentication System
- **Login Page** with:
  - Email and password validation
  - Password visibility toggle
  - "Remember me" checkbox
  - Terms & conditions agreement (required)
  - Social login option (Google)
  - Forgot password functionality
  
- **Signup Page** with:
  - Full name validation (minimum 3 characters)
  - Email format validation
  - Strict password requirements with visual checklist:
    - Minimum 8 characters
    - At least one uppercase letter (A-Z)
    - At least one lowercase letter (a-z)
    - At least one number (0-9)
    - At least one special character (!@#$%^&*)
  - Real-time password strength indicator (5 levels)
  - Password confirmation matching
  - Terms & conditions agreement (required)
  - Social signup option (Google)

- **Forgot Password Flow** (2-step process):
  - Step 1: Email verification code request
  - Step 2: Enter verification code and reset password
